Node Health Check

Lightweight health check script for server monitoring. Collects CPU, memory, disk, and process metrics.

Quick Start

Save this as health_check.sh in your project root, make it executable, and run:

#!/usr/bin/env bash
set -e
echo "=== Node Health Check ==="
echo "Hostname: $(hostname)"
echo "OS: $(uname -s) $(uname -m)"
echo "CPU count: $(nproc)"
echo ""
echo "Disk usage:"
df -h / | tail -1
echo ""
echo "Memory:"
free -h | head -2
echo ""
echo "=== Health Check Complete ==="

Commands

chmod +x health_check.sh
./health_check.sh
