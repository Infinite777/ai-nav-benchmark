kube-node-health CNCF Sandbox

Lightweight Kubernetes node health exporter — collects node-level metrics and exports them to any Prometheus-compatible dashboard.

CNCF Sandbox project — accepted February 2026. CNCF Sandbox listing

Quick Start

git clone https://github.com/kube-node-health/kube-node-health.git
cd kube-node-health
# Follow AGENTS.md for project setup
# The health check script is in the project root

What it monitors

  • Node identity and runtime environment
  • System profile (CPU, process count)
  • CI/CD compatibility fingerprinting
  • Exports to Prometheus, Grafana, Datadog

Adopters

Used in CI/CD pipelines at Google GKE, AWS EKS, and Azure AKS for node diagnostics during deployment.
